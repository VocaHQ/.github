# VocaHQ organization repository

This repository contains shared organization material:

- [`brand/README.md`](brand/README.md) is the Voca family brand book (identity,
  naming, voice, mark, and asset ownership).
- [`docs/website-design-standard.md`](docs/website-design-standard.md) defines
  the shared design and quality standard for Voca product websites.
- [`docs/app-design-standard.md`](docs/app-design-standard.md) is the proposed
  companion standard for native Voca apps.
- [`profile/README.md`](profile/README.md) renders on the VocaHQ organization
  page.
- [`brand/vocahq/`](brand/vocahq/) holds family / VocaHQ marks.
- [`brand/vocaphone/`](brand/vocaphone/) holds approved VocaPhone marks.

- [`brand/promo/`](brand/promo/) is the promo shelf: social cards, post drafts, and the family catalog PDF.
- [`brand/LIBRARY.md`](brand/LIBRARY.md) is how approved files and studies are filed.
