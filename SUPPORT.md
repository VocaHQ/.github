# Getting help

Start with the README in the relevant Voca repository for installation, setup, and troubleshooting. Search existing issues before opening a new one. When reporting a bug, include the app version, operating system, steps to reproduce, expected result, and what happened. Remove tokens, recordings, transcripts, and personal information from logs and screenshots.

For a potential vulnerability, follow [SECURITY.md](SECURITY.md) and report it privately. For conduct concerns, use the contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
