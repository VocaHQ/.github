# macOS press list (VocaMac)

**Use:** tip emails only. Not paid advertorials. **Do not send from this file.**
**Method:** official About / Contact / Tips pages. Directory emails that are not on-site are **UNVERIFIED**.
**Researched:** 24 Aug 2026 (PT).

Product: VocaMac. Beta. macOS 14+ Apple Silicon. WhisperKit / Core ML. Homebrew or DMG. AGPL-3.0. vocamac.com. github.com/VocaHQ/vocamac.

## How to use this list

Personalized tip, not a press-release blast. One platform per email. Lead with on-device / no cloud / AGPL / system-wide dictation. Include a demo URL, GitHub, and one screenshot. Skip UNVERIFIED, DEAD, listing-only, and LATER rows. Do not invent contacts.
