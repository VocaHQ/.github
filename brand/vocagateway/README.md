# VocaGateway marks

Four approved host marks. All use the family microphone from `brand/vocahq/voca-app-icon.svg` (capsule, cradle, stem, base, two side brackets). The chassis is new. The mic is not redrawn.

VocaGateway is optional self-hosted compute. It is never on-device. These marks are the host you run yourself.

## Files

- `vocagateway-1u.svg` / png / 512: one rack unit, mark centered. Default app icon, favicon, and README icon. Holds up at 32px.
- `vocagateway-rack.svg` / png / 512: three-unit stack, mark on the middle unit. Hardware lockup. Do not use it under 64px.
- `vocagateway-tower.svg` / png / 512: standing tower case. Use when the host is a single box, not a rack.
- `vocagateway-twobay.svg` / png / 512: two-bay chassis, mark on the left. Use when the story is a small NAS-style host.

Plate `#0F6B57`. Chassis and mark punch-through `#F2F6F2` / `#0F6B57`. No unique Gateway accent. Dark-first dashboard surfaces stay neutral charcoal.
