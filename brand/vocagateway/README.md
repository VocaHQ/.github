# VocaGateway marks

Two approved rack marks. Both use the family microphone from `brand/vocahq/voca-app-icon.svg` (capsule, cradle, stem, base, two side brackets). The chassis is new. The mic is not redrawn.

VocaGateway is optional self-hosted compute. It is never on-device. The rack is the host you run yourself.

## Files

- `vocagateway-1u.svg` / `vocagateway-1u.png` / `vocagateway-1u-512.png`: one rack unit, mark centered, vents on both sides. Default app icon, favicon, and README icon. Holds up at 32px.
- `vocagateway-rack.svg` / `vocagateway-rack.png` / `vocagateway-rack-512.png`: three-unit stack, mark on the middle unit. Use this when the story is "your own hardware." Do not use it under 64px.

Plate `#0F6B57`. Chassis and mark punch-through `#F2F6F2` / `#0F6B57`. No unique Gateway accent. Dark-first dashboard surfaces stay neutral charcoal.
