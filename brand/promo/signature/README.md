# VocaHQ email signature

Small Gmail block for tester mail from vocahq@gmail.com. Paper and teal. Not a banner.

## Files

- `vocahq-signature.html` is the paste-ready snippet. Image points at the raw file on main.
- `vocahq-mark-48.png` is the live mark (2 KB). `vocahq-mark-64.png` and `vocahq-mark-96.png` if a client needs a denser asset.
- Official geometry is `brand/vocahq/voca-app-icon.svg`. Do not redraw it.

## Paste into Gmail

1. Open `vocahq-signature.html` in a browser.
2. Select the block (mark through vocahq.com).
3. Gmail Settings, See all settings, Signature. Paste.
4. If the mark is blank the first hour after a push, wait for raw.githubusercontent.com or attach `vocahq-mark-48.png` and set the img src to that attachment.
