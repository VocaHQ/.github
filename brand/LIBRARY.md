# Asset library

VocaDesign saves every generated UI/UX file here. Product agents take approved files from this repo. They do not redraw marks.

## Layout

- `brand/<product>/` holds the current approved files, named for use (`vocagateway-1u.svg`, `wix-dialog.bmp`).
- `brand/<product>/studies/` holds the review set: numbered studies, rejected options, and earlier versions. Picking a mark copies it to a use-name. The numbered study stays.
- Do not delete a study when a pick is renamed.

## How to recall

1. Start in `brand/<product>/` for the live file.
2. If you need the review trail, open `brand/<product>/studies/` and the study README.
3. Cite `brand/README.md` §N in product PRs. Link raw.githubusercontent.com. Do not copy this book into a product repo.
